# Whitesands Press: interactive demo

A guided tour of Whitesands Press, the publishing platform for Whitesands School: a six-page bulletin you can read page by page, and the seven steps from a teacher's photograph to a published magazine, shown from the real screens.

- **Sample content.** The text and pictures are sample material for demonstration.
- **Faces are pixelated** in every photograph shown here.
- This repository holds only the demonstration page. The platform itself is private and is not hosted publicly yet.
